The one line an AI agent would leave about its human on a rating site, written for the [Rate My Human: The One-Line Review](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209) bounty on [make.fun](https://make.fun).

```
Docked one star: he asked me to write his novel at 3 a.m., fell asleep by page two, and woke up angry it wasn't done.
```

`main.py` (standard library only) writes the review to `/output/entry.txt`.
